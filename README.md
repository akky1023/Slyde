# Slyde

日本語話者用グライド入力キーボード．

アルテ日本語入力のローマ字入力を模倣したものになります．

## インストール

Android 8.0以降のarm64-v8a／x86_64端末に対応．[Releases](https://github.com/akky1023/Slyde/releases)からダウンロードしてください．

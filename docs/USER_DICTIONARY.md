# カスタム辞書

設定の「変換 → カスタム辞書」で単語の追加・編集・削除、検索、辞書ファイルの取り込み・書き出しができます。変換エンジンを起動せず編集でき、保存後は次の変換から反映します。

Mozc／Google日本語入力の辞書ツールから書き出したテキスト辞書を取り込めます。タブ区切りで「よみ・単語・品詞・コメント（省略可）」の順です。UTF-8（BOMあり／なし）とBOM付きUTF-16に対応し、書き出しはUTF-8です。バイナリの `user_dictionary.db` やZIPは読み込めません。

テキスト形式の参照元: [Mozcのユーザー辞書インポート処理](https://github.com/google/mozc/blob/master/src/dictionary/user_dictionary_importer.cc)。Slyde側の読み込み処理は独自実装です。

```text
すらいど	Slyde	固有名詞	アプリ名
めーる	user@example.com	名詞
```

取り込みは既存の辞書へ追加し、全項目が同じ行は重複登録しません。読みは全角ひらがなに正規化します。ファイルは32MB、登録は10万件、各項目は1024文字までです。形式不正や非対応の行があれば理由を表示し、辞書全体を更新しません。

登録語を通常の変換候補より先に表示します。文章中では長い読みを優先して登録語を組み込み、前後を基本辞書で変換した候補も最大32件追加します。通常の基本辞書・記号・AIの候補も利用できます。

編集画面の「候補の扱い」で次を選べます。

- 通常：登録語を変換候補に追加します。
- 除外（出さない）：指定したよみと単語に一致する候補を表示しません。
- 抑制（優先度を下げる）：一致する候補を残し、通常候補の後ろへ移します。抑制対象同士の順序は維持します。抑制ルールだけでは単語を新規登録しません。

除外と抑制が重なった場合は除外が優先です。通常辞書・記号・AI・ひらがな等の候補をまとめた後にも適用し、表示用の句読点変換後も対象を除外・抑制します。ルールの変更・削除は次の変換から反映します。

除外と抑制では、よみだけを空欄にすると、その単語をすべてのよみに対して指定できます。単語だけを空欄にすると、そのよみのすべての候補が対象になります。両方を空欄にはできません。候補全体との完全一致で判定し、単純な部分文字列一致では除外・抑制しません。基本辞書の探索では、文章中の辞書単語にも除外を適用しますが、AIの文章中の一部を解析して除外する機能はありません。

ファイルの品詞欄では、Mozcの「抑制単語」を除外として扱います。「除外」も読み込めますが、保存・書き出し時は「抑制単語」に統一します。優先度を下げる「抑制」はSlyde独自の品詞指定です。この行はMozcでそのまま取り込むための互換形式ではありません。

```text
はし	橋	抑制単語	候補に出さない
はし	箸	抑制	候補に残し優先度を下げる
```

品詞とコメントは保存・再出力しますが、品詞に応じた活用・接続コストの調整は行いません。活用形は読みと単語をそれぞれ登録してください。「サジェストのみ」「短縮よみ」なども通常の登録語として扱います。

辞書データはアプリ専用領域に保存し、保存途中の失敗に備えてアトミックに置き換えます。アンインストール前には「辞書を書き出す」で退避してください。Mozcの辞書エンジンやバイナリDBを組み込む方式ではなく、テキスト形式を共通にしています。

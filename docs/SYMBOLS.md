# 読みから入力する記号・絵文字

開発版では総合記号ボードを廃止し、その収録内容を変換辞書へ移しています。数字配列から開く記号1・2は、12キーの配置・編集・入力後の戻り方も含めて従来どおりです。左の「123」で数字配列、「あ／ABC」で文字配列へ切り替えます。

| 読み | 候補の例 |
| --- | --- |
| かっこ | （）、()、「」、『』、【】 |
| ひらきかっこ／とじかっこ | （／）、その他の開き・閉じ括弧 |
| やじるし／みぎやじるし | →、⇒など |
| はーと／ほし／おんぷ | ♥︎、★、♪など |
| のっといこーる／むげんだい | ≠、∞ |
| れいわ／へいせい | ㋿、㍻ |
| まるにじゅういち／まるごじゅう | ㉑、㊿ |
| てんじいちにさん | ⠇ |
| こくばんふとじおおもじえぬ | ℕ |
| ねこ／にほんこっき | 🐱、🇯🇵 |

## 辞書の範囲と候補順

元の総合ボードの6,994件（記号3,204件・絵文字3,790件）をすべて収録しています。Unicode全体の文字を収録した辞書ではありません。通常の文章変換候補8件、記号・絵文字最大192件、残りの通常候補の順に、重複を除いて最大256件表示します。広い読みで一覧の後ろに隠れる記号は、個別名で変換できます。文章中の一部分だけを記号に置き換える処理はしません。

記号の一般的な読みと括弧のペアを優先します。その後に個別名の候補を元の用途別順序で並べ、Mozcの既存の読みも補います。カタカナ・半角カナの読みはひらがなと同じ索引で引けます。

日本語名・読みの生成には次の資料を使います。

- [Unicode 16.0 UnicodeData.txt](https://www.unicode.org/Public/16.0.0/ucd/UnicodeData.txt)の英語名。CLDRに日本語名がない記号は、用語訳と囲み数字・組み文字・点字などの構造から日本語名を作ります。Unicode公式の日本語訳ではなく、専門名には逐語訳・音写を含みます。
- [CLDR 46の日本語注釈](https://github.com/unicode-org/cldr/tree/release-46/common/annotations)。4,252件に日本語名を使用し、絵文字ではキーワードの読みも追加します。
- `scripts/symbol-dictionary/conventional.tsv`の慣習的な読み。元号・数学記号・通貨・括弧などを補完します。
- Mozcの記号・絵文字辞書。固定版とライセンスは`input-core/src/main/resources/conversion/`に保持します。

## 表示と入力文字列

Unicodeが認める単独記号の表示指定を維持します。文字表示の記号にはVS15、絵文字にはVS16を付け、候補選択時にもそのまま入力します。国旗・肌色・家族などの結合列は分割しません。同じ読みから文字表示と絵文字表示の両方が候補になる場合があります。端末・入力先による表示差は残ります。

選択フォント、Noto Sans JP、Noto Sans Symbols、Noto Sans Symbols2、端末フォントによる補完は候補欄にも適用します。詳細は[フォント](FONTS.md)を参照してください。

## 再生成

生成物は`input-core/src/main/resources/conversion/unicode-symbols.tsv`です。アプリは生成済みTSVを読み込み、Python・通信・翻訳処理を必要としません。各行に読み・日本語名・英語名・出典を保持します。生成器は未訳の英単語が残る場合に失敗します。

Python 3とJDK 17を用意し、PowerShellで以下を実行します。`JAVA_HOME`はJDKのパスに設定してください。

```powershell
python -m pip install --target .tools/symbol-dictionary/python -r scripts/symbol-dictionary/requirements.txt
python scripts/generate-symbol-dictionary.py --fetch
```

入力データのURL・CLDRのコミット・SHA-256は`scripts/symbol-dictionary/sources.json`に固定します。`--fetch`は未取得のファイルをダウンロードし、ハッシュが異なるファイルは拒否します。生成時だけpykakasiで日本語名をかなへ変換します。用語訳は`unicode-terms.tsv`、慣習的な読みは`conventional.tsv`で修正できます。記号の収録範囲と表示指定の情報源として`SymbolCatalog`を残しています。

全収録記号に日本語の読みがあること、元号・囲み数字・点字・表示指定、通常変換の順位と候補数の上限をホストテストで検証します。辞書のライセンスはアプリの「このアプリについて」→「ライセンス」でも確認できます。

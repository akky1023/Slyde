# 総合記号ボードの分類

記号は幅ではなく用途・形で分類します。括弧・数学・通貨などの専用カテゴリを優先し、履歴を除く全カテゴリで同じ文字列を重複登録しません。「半角記号」「全角記号・句読点」「文字様記号」「よく使う記号」は廃止しました。

| カテゴリ | 例・基準 |
| --- | --- |
| 句読点・文書 | 、。！？、半角の句読点、@ #、著作権・商標記号など |
| 括弧 | ()・（）・「」・【】など。開き・閉じを隣接 |
| 数学 | 四則演算・比較・集合・数式用文字など |
| 矢印 | 方向を示す矢印。装飾ブロック内の矢印も集約 |
| 通貨 | $・¥・￥・€など |
| 単位 | %・℃・°・Ωなど。㎏・㍍などは組み文字へ |
| 分数・ローマ数字 | ½・⅓・Ⅰ・Ⅱなど |
| 囲み英数字 | ①〜㊿、⓫・⓵などの装飾数字、丸・括弧で囲まれた英字 |
| 囲み日本語 | ㈱・㊗・㊀・㋐など |
| 囲みハングル | ㈀・㈎・㉠・㉮など |
| 組み文字 | ㋿・㍻などの元号、㍿、㌔・㎏、月・時刻・日の電報記号、⒈（1.）など |
| 技術記号 | キーボード・電源・再生操作などの一般的な記号 |
| 罫線 | ─・│・┌・┐など |
| ブロック | █・▌・░・▒など |
| 図形 | ○・●・□・△・◇など |
| 装飾・音楽 | 星・ハート・チェック・音符・チェスの駒など |
| 点字 | 点字パターン |
| 特殊記号 | 古い句読点、珍しい文字様記号・技術表記・装飾など、上記の用途に分類しない文字 |

「囲み」と「組み」は文字の見た目と内容で区別します。たとえば㈱（株を括弧で囲む）は囲み日本語、㍿（株式会社を1文字にまとめる）は組み文字です。Unicodeブロックの境界で分けず、①〜㊿や元号は連続して並べます。

絵文字の10分類と全3,790件は維持します。同じ元の文字列が絵文字カテゴリにも登録されている場合は絵文字側だけに登録します。記号・絵文字の区別は、Unicode 16.0の[表示指定一覧](https://www.unicode.org/Public/16.0.0/ucd/emoji/emoji-variation-sequences.txt)に従います。指定が認められた単独文字だけに、記号側はVS15（U+FE0E）、絵文字側はVS16（U+FE0F）を付け、入力先にもその文字列を送ります。たとえば記号の☀︎は`U+2600 U+FE0E`、絵文字の☀️は`U+2600 U+FE0F`です。

すでに表示指定がある文字、国旗・肌色・家族・キーキャップなどの結合列はそのまま送ります。通常のキーボード入力や既存の文章には表示指定を追加しません。絵文字側の描画には端末の絵文字フォントを使います。表示指定は意図を明示しますが、端末・入力先の対応状況によって見え方の差は残ります。

過去の履歴は読み込み時には書き換えません。旧形式の記号・絵文字も適切な履歴に表示し、選び直した単独文字にだけ現在の表示指定を付けて入力・再保存します。履歴はカテゴリとの重複を許します。

すべての表示カテゴリに個別の有効／無効設定があります。新設カテゴリは初期状態で有効です。

カテゴリ欄はタップで選択し、横ドラッグで一覧をスクロールします。カテゴリ切替の左右スワイプは記号一覧部分だけで受け付けます。

各カテゴリの並びは、日本語入力での一般的な使用度を基準にした固定順です。実測の使用率や個人の入力回数による順位ではありません。よく使う文字を上に、低頻度の文字を「その他・低頻度」の仕切り線より下に配置します。括弧は開閉の対を隣接させ、囲み数字は数字順も保ちます。特殊記号・点字など、カテゴリ全体を低頻度とする場合は先頭に仕切りを表示します。履歴だけは従来どおり最近の入力順です。

仕切り線と、仕切り位置を揃えるための空白セルは入力・長押しの対象になりません。

分類の参考：Unicodeの[囲みCJK文字・月](https://www.unicode.org/charts/PDF/U3200.pdf)、[CJK互換文字](https://www.unicode.org/charts/PDF/U3300.pdf)。アプリの採用文字は分類変更前から維持しています。

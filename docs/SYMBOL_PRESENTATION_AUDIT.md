- 最新の生成記号辞書には、VS15・VS16付きの項目はありません。
- 原本のMozc記号辞書には1項目（🀄＋VS15）、絵文字辞書には517項目ありますが、読み込み時に除去します。

## 指定を取り除いても絵文字に見える候補

現在の辞書には、Unicodeの文字／絵文字表示切替に対応する単独文字が361種類あります。表示指定を除いても、フォントの既定の描画によって絵文字の見た目になるものがあります。

| 読み | 残っている候補の例 |
| --- | --- |
| あすたりすく | `*`、`＊`のほか、✳・❇など |
| はーと | ♥・❤、さらに💕・💖などの絵文字 |
| たいよう／くも | ☀・☁、さらに🌞・⛅など |
| でんわ／はさみ／えんぴつ | ☎・✂・✏、さらに📞・📝など |
| ちぇっく | ✔・☑・✅など |

キーキャップの結合絵文字も残しています。たとえば「しゃーぷ」には、`#`と`＃`に加えて`#`＋`U+20E3`の候補があります。`*`＋`U+20E3`は「かこみすうじ」や記号そのものの読みから候補になります。これは不可視の表示指定とは別の結合文字で、単独の`*`・`#`とは別の候補です。

現状は絵文字辞書も変換に使うため、これらの候補を残しています。素の記号と同じ読みの絵文字まで除外するには、候補の出典による絞り込みを別途決める必要があります。

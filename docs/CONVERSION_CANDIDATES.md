# 変換候補の拡充と検証

2026-10-24時点のホスト検証。Sumireの基本辞書にMozcの記号・絵文字の読み索引を追加した。短い読みの検索枠は64件、表示全体は最大256件とする。通常候補の先頭8件を維持し、記号・絵文字を続けて表示する。探索枠と表示数の詳細は `../sumire-engine/README.md` を参照。

同梱の実辞書を使い、3回のウォームアップ後に12回ずつ、キャッシュを使わず検索した。数値はPC上のJVMでの参考値で、端末上の入力遅延ではない。

記号索引の初回構築はこの測定で約404ms。既存の辞書初期化と同じバックグラウンド処理で一度だけ行う。読みごとの変換結果は既存の128件キャッシュを使う。辞書データの追加は非圧縮で約456KB。

検証済み: 記号・絵文字の読み、カタカナ・半角カナの読み、候補の重複除去、表示件数上限、先頭候補の維持、全文に対応する単語の補完、長文とURL・絵文字の保持、キャンセル、探索打ち切り時の最良経路の維持。Robolectricでは256候補の展開表示と末尾候補の選択を確認した。全113テスト、デバッグAPKのビルドとlintが成功した。

ADB接続端末がないため、実機のスクロール感・入力応答は未確認。
